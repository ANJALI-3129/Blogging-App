# Realtime Blogging Platform

A modern realtime blogging platform built using React.js and Firebase.  
Users can create, edit, and delete blogs with realtime Firestore updates and a responsive modern UI.

---

# 🚀 Features

- Create Blogs
- Edit Existing Blogs
- Delete Blogs
- Realtime Firebase Firestore Updates
- Responsive UI Design
- Character Counter
- Dynamic Document Title
- Clean Modern Styling
- React Hooks Based Architecture

---

# 🛠️ Tech Stack

- React.js
- Firebase Firestore
- CSS3
- JavaScript (ES6)
